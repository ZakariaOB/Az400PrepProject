- In order to create your resource directly from azure you have to 
  - Create from template and use the right template .
  - For ssql server : You will need 2 resources , database and a server .

- Deployment modes 
  - Incremental : resources will not interfere with resources created 
   on the resource group .
  - Complete Mode: In complete mode, the deployment is not selective or incremental. 
    Instead, it treats the ARM template as the single source of truth for the entire 
    resource group and ensures that the resource group's configuration matches the template exactly. 
    This means it can create new resources, update existing ones, and delete any resources not defined in the template.
