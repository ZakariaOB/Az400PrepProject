# Azure boards

- Planning work items: Task, User stories etc ..
- In 'Basic mode' you are not able to create 'Tasks' and 'User stories'
- If you choose Agile project you will be able to create a project where you can add: User stories
- You can have organisations inside your project: Each one could have it's own projects (related projects)
- To create an agile project: New project > Advanced > Choose Agile project

- Epics are mean to have multiple user stories inside them
